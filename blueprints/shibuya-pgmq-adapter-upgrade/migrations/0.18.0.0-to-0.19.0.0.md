# PGMQ adapter 0.18.0.0 → 0.19.0.0

## Precondition and cohort

The consumer crosses from adapter 0.18 to 0.19. Find owned `PgmqAdapterConfig`
constructors and Shibuya `Adapter` constructors, including fakes, plus assertions
and operational queries that depend on processing spans. Unused surfaces are not
applicable. Resolve adapter `^>=0.19.0.0` and Shibuya core/metrics `^>=0.13.0.1`.
The compatible Kiroku adapter, where used, is `^>=0.8.0.0` from
mori://shinzui/kiroku/packages/shibuya-kiroku-adapter. Verify published versions
rather than forcing a solve with `allow-newer`.

## Source and trace adaptations

- `PgmqAdapterConfig` gains strict `telemetry :: AdapterTelemetry`. Existing
  record updates of `defaultConfig` need no change; full literals must supply
  `defaultAdapterTelemetry` or an explicitly chosen policy.
- Shibuya's `Adapter` also gains strict `telemetry`; update owned constructors
  and fakes. Start from `defaultAdapterTelemetry` when selecting options.
- The default `ParentAndLink` keeps a delivery in the sender's trace and adds
  a link. `defaultAdapterTelemetry {traceCorrelation = LinkOnly}` starts a new
  root linked to the sender, useful for delayed delivery and retries. Choose
  based on the consumer's documented requirements. Without a usable W3C
  traceparent, ambient parenting remains and no creation link is added.
- Processing spans change from `<processor> process` to `process <processor>`
  and gain `messaging.operation.name = "process"`. Batch processing spans are
  roots with at most 128 creation links and a `shibuya.batch.links.dropped`
  count. Update owned trace assertions and matching queries. Report external
  dashboards or alerts that still need their owners' changes.
- With `LinkOnly`, dead-letter traceparent identifies the delivery's processing
  span; the original sender is preserved as `x-shibuya-upstream-traceparent`.
  Adapt assertions that assumed those contexts were identical. Preserve retry,
  DLQ payload, acknowledgement and redrive behavior.

No database migration is introduced by this adapter edge. Do not drop databases
or rewrite migration checksums.
